A collection of Python and Bash scripts developed during my work as a structural biologist and cryo-EM facility staff scientist. The repository spans scientific data management, cryo-EM facility operations, HPC pipeline development, structural data analysis with the RCSB Protein Data Bank and Electron Microscopy Data Bank, and system administration tools built for shared research computing environments.

---

## Repository Structure

### 🔬 Cryo-EM
Scripts supporting cryo-EM data collection, processing, and workflow management. Includes tools developed for single-particle analysis pipelines using RELION and cryoSPARC, session management, and data quality monitoring.

### 🧬 EMDB
Python scripts for interacting with the Electron Microscopy Data Bank (EMDB) via its REST search API, plus cross-database tools linking EMDB to RCSB PDB and AlphaFold DB. Includes deposition lookup and career-timeline visualization, resolution/method trend analysis, a validation report QC analyzer, a deposition completeness checker, and a field-wide EMDB statistics dashboard. Developed as part of a self-directed study of EMDB/wwPDB data standards and the OneDep curation workflow.

### 🗄️  RCSB PDB
Python scripts for interacting with the RCSB Protein Data Bank programmatically via the RCSB Search and Data APIs. Includes novel use cases for extracting and cross-referencing structural metadata, exploring PDBx/mmCIF data standards, and automating structure annotation workflows. Developed as part of an in-depth self-directed study of the wwPDB ecosystem and validation pipeline.

### 🖥️  HPC
Scripts for high-performance computing environments (Slurm, PBS). Includes job submission templates, pipeline automation, and monitoring tools developed for cryo-EM data processing on institutional HPC clusters.

### 📊 EMhub
Scripts interfacing with EMhub, an open-source facility management platform for electron microscopy facilities. Includes tools for scheduling, session tracking, and data reporting developed for a shared cryo-EM facility environment.

### 👥 User_Management
Tools for managing user accounts, permissions, and access in a multi-user shared research facility environment.

### 🖧 System_Monitoring
Scripts for monitoring system health, storage utilization, and instrument status in a cryo-EM facility context.

### 🗂️  File_Operations
Utilities for file management, data organization, and archiving, particularly for the large datasets generated by cryo-EM data collection sessions.

### 🌐 Network
Network configuration and monitoring scripts for research facility infrastructure.

### 📧 Emails
Automated email notification scripts for facility operations, including alerting for instrument status, session reminders, and data management notifications.

### 📈 Graphviz
Visualization scripts using Graphviz for generating workflow diagrams and data flow charts relevant to cryo-EM processing pipelines and facility operations.

### 📁 Documentation
SOPs, workflow guides, and technical documentation developed for cryo-EM facility users and staff. Covers vitrification protocols, data collection procedures, HPC job submission, and data management best practices.
